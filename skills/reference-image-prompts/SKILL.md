# 参考图风格解析与图片提示词

## 输出约定

- 默认仅输出一份可复制的完整中文静态图片提示词。用户要求分析、教学或多个版本时再添加相应内容；可用 writing block 呈现。
- 正文最多1024字符，含标点、空格、换行，通常控制在700–950字符。用户指定其他上限时遵从；包装标记不计入正文。
- 默认使用自足描述，不写“图二”“网上找的图”及依赖上下文的指代。只有用户明确要求引用编号时才保留。
- 仅设计提示词。在已建立的提示词编写语境中，“生成类似某图”不代表授权自动出图。明确要求实际出图时使用对应图像技能。

## 工作流程

### 1. 查看图片，确定分工

遵从当前用户指示，区分风格、动作、构图、人物身份与目标内容参考。同一图片可承担多个明确角色。图片顺序清楚时直接处理；核心分工不明且会改变结果时只问一个关键问题。

实际查看全部相关参考图。优先读取附件本地副本；读取报错时检查已提供目录的真实路径，仍不可读则说明缺失并请求对应图片，不从文件名或报错编造内容。

风格参考不自动等于人物身份参考。仅迁移用户指定的面部、服装、场景等内容。动作参考只贡献姿态和接触关系，不带入其面容、滤镜、衣服、食物或背景。

### 2. 提取可执行的风格基线

在内部明确以下信息，不必逐项输出分析：
- 画风：摄影、插画、三维等，以及真实或风格化程度。
- 色彩：主色、辅助色、饱和度、肤色与冷暖关系。
- 明暗：整体曝光、黑位、暗部细节、高光过渡和反差。
- 光线：可观察的方向、软硬、轮廓光、环境反射光。
- 成像和材质：皮肤、布料、木石等纹理，锐度、颗粒、景深和背景虚化。

不要把无法确认的时间、季节、器材和数值当成事实。多张风格图取共同特征，冲突以指定主参考为准；未指定且冲突显著时简短澄清。

### 3. 重构单帧画面

保留核心行为、主体关系和指定替换，交代人数、方位、姿态、表情、视线、手和道具归属。将连续行为凝练成一个静态瞬间，不写时间轴、对白、音效或运镜。

多人场景明确各自操作区域，避免多只手交错控制同一物体；工具接触、重力、人物尺度和遮挡应合理。

食物替换同步更新色泽、形态、装饰、断面、原料及工序，删除旧食物残留。不为模仿动作强造错误工序；不确定的专门知识只有影响结果时才核实。

环境远景继承调色和材质，不机械照搬人像浅景深、皮肤或服装要求。保持建筑、河岸、地形纵深，采用自然空气透视。

### 4. 保持系列一致

沿用当前可见上下文内已经确认的风格、角色要求和食物设定，最新明确修改优先。将风格基线压缩为可复用的实质描述，但不得把乡村、绿豆糕、低曝光或暖金光固化为通用默认。

区分画风一致和构图一致：只要求画风时可按目标动作调整构图。不要承诺跨会话自动记忆或完全复现；关键参考不可见且决定结果时取得参考，不凭空猜测。

### 5. 整理并验证

按需组织：主体和关键瞬间、环境和构图、光影色彩与材质、少量针对性限制。重要内容放前面，删除重复修饰、无关布景及占位符。不要虚构分辨率、种子或模型设置。

检查参考分工无串用，人数及替换一致，无未授权身份替换，无视频指令，无光线景深冲突，负面词不否定主动作。

用 scripts/check_prompt_length.py 统计最终正文。超限时先删重复形容词、次要布景和泛用负面词，保留动作与风格，压缩后重新检查。不得未经计数就声称满足限制。

处理参考分工、食物替换、远景或其他风格迁移时阅读 references/examples.md。
